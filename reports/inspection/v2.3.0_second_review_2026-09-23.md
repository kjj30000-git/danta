# v2.3.0 2차 비판적 리뷰

## 발견 및 수정

- legacy SUPPORT/RECLAIM 함수는 보존됐지만 구 설정명 5개가 사라져 비활성 경로 호출 시 `NameError` 가능성이 있었다. 신규 조건을 바꾸지 않고 호환 alias를 복구했다.
- SNAPSHOT 평가 종료 비교가 15:20 정확한 시각까지 `NOT_REACHED`로 처리할 수 있었다. 인수인계서대로 15:20은 평가하고 15:20 이후만 `NOT_REACHED_SESSION_END`가 되도록 수정했다.
- 프로그램은 20:00까지 실행되므로 15:20 이후 구조 판정이 계속될 여지가 있었다. 15:20 이후에는 신규 구조·snapshot 평가를 중단하도록 명시했다.
- 기존 v2.2.0 장외 fixture가 새 mode 배열에 의존하는 문제를 피하고, v2.3.0 전용 무외부연결 검증 함수로 교체했다.
- 첫 실행에서 `validate_v21_opening_leader_config()`의 `STRATEGY_VERSION == "v2.2.0"` exact-lock이 확인됐다. 관련 버전 assertion을 전수검색해 v2.3.0을 허용하도록 수정했다.

## 보존 확인

- 주문·broker·live 관련 핵심 정의 49개는 부모 AST와 동일하다.
- BASE/FIRST_75·ETF·REST admission·WebSocket live-first 경로를 재작성하지 않았다.
- legacy SUPPORT/RECLAIM 신규 생성은 OFF이고 과거 함수·컬럼은 남아 있다.
- 실제 기본 시작 순서를 직접 호출하여 로그 출력과 모든 사전 validator를 거쳐 Kiwoom token 요청 경계까지 도달함을 확인했다.

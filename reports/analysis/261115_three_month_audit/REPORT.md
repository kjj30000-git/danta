# 261115_3개월 전략·데이터 신뢰도 재평가와 다음 연구 사전 기준

기준일: 2026-11-15 KST. 원본 GitHub main: `6b794c662e0448694419f4acb5626467d443fbfe`.

## 결론

**현재 수익성이 입증된 전략도, 곧바로 승격할 유력 후보도 없다.** 기존 전략의 실패를 표본 부족만으로 설명할 수 없다. 특히 v2.3.3의 BASE/FIRST·STRUCTURE·SNAPSHOT은 저장된 대표 조합에서 비용 전부터 평균 음수다. 반면 장기 보합과 새 첫 눌림은 표본·데이터 선택·집행 가정 때문에 확실한 결론을 내리기 어렵지만, 이는 긍정 근거가 있다는 뜻이 아니다.

우선 검토할 가설은 **최대 1개: 관측 대상을 바로잡은 장초반 주도주 첫 눌림 재돌파**다. 이것은 유망 판정이 아니라 제한된 반증 실험이다. 기존 무제한 후보 첫 눌림은 탈락이다. 두 번째 후보는 선정하지 않는다. ETF·보합·TP/SL 최고조합을 빈자리에 넣지 않는다.

운영 노트북·설정·원본 데이터는 변경하지 않았다. 실행·주문 API를 호출하지 않았다. RESEARCH 유지, 이번 작업 실제·키움 모의주문 0건. 과거 실전 원장은 별도이며 과거 전체가 주문 0건이었다는 뜻은 아니다.

## 확인 범위와 재현 한계

README.md, CURRENT.md, DATA_ANALYSIS_GUIDE.md, ANALYSIS_HANDOFF_GUIDE.md, 최신 v2.3.4 인수인계와 기존 분석·오류 보고서, releases의 19개 노트북, 첨부 v1.6 소스를 대조했다. 각 릴리스의 코드 셀을 전체 추출하고 AST로 함수 정의·변경을 점검했으며 수집·진입·청산·복구 관련 경로를 직접 확인했다. 함수별 AST 해시는 function_versions.csv에 남겼다. 이것이 모든 함수의 동적 재검증 또는 장중 재실행을 뜻하지 않는다.

`data/`의 543개 파일에 대해 목록·크기·CSV 구조 또는 JSON/.bak 파싱을 조사했다. CSV에서 읽힌 데이터 행은 10,778,200행이며 독립 거래 수가 아니다. SQLite는 읽기 전용 quick_check=ok, events 59,082행과 CSV 59,082행의 수를 확인했다. DB·CSV 모든 필드의 동등성이나 업로드 순간의 DB/WAL/SHM 원자적 스냅샷까지 증명하지 않았다. 바이너리 상태파일은 거래 표본으로 합산하지 않았다.

중요한 불완전성:

- 저장소 릴리스는 v1.6.7부터다. v1.4·v1.5·v1.6.1~v1.6.6의 실행 당시 소스 전체가 모두 보존돼 있지는 않다. 첨부 v1.6은 해당 모든 일자의 실제 실행본이라는 증거가 없다. 따라서 **모든 과거 버전의 실제 실행 코드를 완전히 확인했다는 주장은 할 수 없다.**
- 1.6 폴더의 CSV version에는 v1.6.1이 기록된다. 폴더명을 실행 버전으로 강제하지 않았다.
- 초기 파일은 trade_id/entry_mode가 없으며 v1.4·v1.5는 strategy 명명도 다르다. 현대 대표 조합과 무리하게 합산하지 않았다.
- v1.6.4·v1.7.0 시스템 로그에 각각 UTF-8 손상 위치가 있다. 대체 디코딩상 각 1개 replacement이며 원문 해독 성공으로 처리하지 않았다.
- CSV 폭 불일치: v1.6.2 paper_entry_decisions 34행, v1.6.6 live_orders 15행. 해당 필드를 정상 파싱된 분석 근거로 사용하지 않는다.
- 과거 넓은 연구표본, MAIN 09:05~09:30 부분표본, 실제 예산 적용 표본은 별도다. 시간 밖 FIRST 가상진입 자체는 시간 gate 훼손의 증거가 아니다.
- PRE_HISTORY 중 pre_entry_type=FIRST_75_PASS만 FIRST로 분류했다. PRE_HISTORY 전체를 FIRST로 부르면 LATER_PASS가 섞인다.

version_summary.csv는 버전·폴더별 대표 결과의 기술통계이며 미관측 청산을 0으로 채우지 않았다. 초기 버전의 net 공란은 저장된 순수익이 없다는 뜻이다. portfolio_daily_all.csv의 초기 net은 비교용 가정 gross−0.24%이며 당시 확정 비용·실계좌 수익이 아니다. 모든 버전 성과를 하나의 평균으로 합치지 않았다.

## 사전 통과·탈락 기준 제안

최소관찰은 검정력을 보증하는 마법 숫자가 아니라 최소 하한이다. 약2% 변동성에서 평균0.2%의 작은 우위를 구분하려면 단순독립 가정에서도 수백 건이 필요하고, 날짜·종목 군집은 필요량을 늘린다.

## 과거 실제매매 원장 보조 점검

업로드된 v1.6.6~v1.7.1.3 live_trades는 기록된 청산27행, live_realized_pnl 합계 −111,059원이다. 폴더별 결과는 historical_live_summary.csv에 남겼다. 이는 gross 원장값으로 수동매도·종료누락·계좌 전체 체결의 완전성을 증명하지 못하므로 실제 계좌 전체 성과나 비용 후 전략 검증으로 채택하지 않는다. live_orders 폭오류·주문상태와 종목별 실현손익 조회 파일의 범위가 다르므로 서로 더하지 않았다. 현재 RESEARCH 주문0건 조건과 과거 실제매매 이력은 분리했다.

검토: 2026-11-15 KST. broker 인증·조회·주문 호출 없이 공식 공개 문서/예제와 저장 데이터를 확인했다. 장중 실수신 검증과 구분한다.

## 공식 계약

- [키움 공식 API 스펙](https://github.com/Kiwoom-Securities/Kiwoom-REST-API/blob/c7a3d25449ed4b4238bef378780c41103c67b9e9/kiwoom/_data/kiwoom_api_spec.json): 0B field13 누적거래량(주),15 부호 있는 단일 체결량,14 누적거래대금(백만원),20 HHmmss,16 시가,290 장중=2. 누적량 증분과 단일량 절대값을 대조하고 누락·역행은 구간을 나눈다. 가격×누적량을 매틱 더하지 않는다.
- 같은 스펙의 0D: 21 호가시각,41/51 매도/매수1호가,61/71 매도/매수1호가잔량. 부호 있는 가격은 절대값으로 정규화한다. 서버 sequence가 없으므로 같은 시각·가격·잔량 snapshot은 재사용하지 않는다.
- 0J: 20 시세시각,10 현재값,16 시가. 판단시각 t−60/t−300 기준, 앵커 허용오차15초. 신호경로에서 REST를 기다리지 않는다. BASE 군은 지수 결측만으로 차단하지 않는다.
- ka10080: `/api/dostk/chart`, KRX plain code, tic_scope=1, upd_stkpc_tp=0. `stk_min_pole_chart_qry`의 cntr_tm/OHLC/volume을 사용한다. 시각 label의 시작/종료 의미를 임의 확정하지 않는다. **서로 다른 모양의 실제 정상 KRX 완료봉 2개와 동일 label의 OHLCV가 정확히 일치한 후보만** 참조 초기화를 허용한다. 불일치·평평한 동일봉·자료부족은 평가불가/미확인이다. 09:00~04 다섯 봉과 09:05 이후 연속성이 필요하다. 과거 신호·체결을 소급 생성하지 않는다.
- [KRX 호가가격단위](https://regulation.krx.co.kr/contents/RGL/03/03020100/RGL03020100.jsp): 보통주 가격대별1/5/10/50/100/500/1000원, 가격대 경계의 다음/직전 호가를 별도 시험했다.

## 상품분류

키움 ka10099/ka10100 응답만으로 우선주·SPAC을 모두 확정하지 않고, 로그인 없는 [한국투자증권 공식 공개 종목 마스터](https://github.com/koreainvestment/open-trading-api/tree/4a51f9126e719c352072b14b7df9222cb2691720/stocks_info)의 그룹·우선주·SPAC 필드를 사용한다. 종목명을 보통주 확정 근거로 쓰지 않는다. 원시 ZIP은 공식 공개 download 주소에서 실행 당일 읽기 전용으로 취득하며 TLS 검증을 끄지 않는다. 요청 실패·분류 미확인은 신규 해당 종목 평가불가다. 추가 계좌/인증키는 필요 없다.

공개 KOSPI master 검사: ZIP SHA256 `19de09a78b79d8bc304536a9029410f47dee68e25e0fb9b9975d55f0c05800c9`, 파싱2118개, 보통주801개. 005930/035420 보통주,005935 우선주,069500 ETF를 확인했다. schema의 widths와 index는 `master_schemas.json`에 고정했고 노트북에 내장한다. builder도 이 파일을 사용하며 `/tmp`나 외부 clone에 의존하지 않는다.

## 과거 입력 가용성

| 저장 자료 | 가능한 진단 | A/B 완전 재현 불가 항목 |
|---|---|---|
| v234 opening BAR | 관측된 후보의 minute/high/close/valid/reason | low·거래량·분당 실체결대금·호가·잔량 부재 |
| pullback_candidate_1m | 선택 후보의 등록 후 OHLCV·연속성 | 전체 rank 모집단의 최초5분 및 호가 완전성 보장 없음 |
| scanner_signals | 선택된 신호의 실제/추정 거래대금·시장·변동률 | 전체 시점별 모집단·분봉별 실거래대금 아님 |

누락 조건을 생략한 근사 백테스트를 A/B 원래 규칙의 성과로 보고하지 않았다. 과거 양의 기대수익은 미확인이다. 기존 3개월 감사의 음수 성과와 새 A/B 확인 표본을 합산하지 않는다.

## 집행·분모의 명시적 가정

- 각 정책의 공유600만원/종목100만원/동시5/하루5/동일종목1회. 지연1/3/5초는 각각 독립 원시호가 재생 시나리오다. **원래3초 대기기한을 연장하지 않으므로 3/5초 지연은 NO_FILL이 될 수 있다.** 비용상수 차감으로 지연을 대신하지 않는다.
- PAIR 계정은 신호별 자금제약 이전의 반사실 한 거래다. INDEX_UP의 동일 신호 PASS/FAIL/데이터불가를 붙여 피한 손실과 놓친 수익을 비교한다. 공유 계좌와 합산하지 않는다.
- 주 결과는 ask/bid 가격에 추정 비호가 왕복0.24%를 추가한 보수적 모델. REFERENCE 신호 기준 gross−0.24%와 별도다. 추가0.10/0.20/0.40%p는 마찰 민감도다.
- 평가 가용성은 후보×전략×완료 판단분의 실제 평가를 분모로 한다. 이론적으로 완료봉2개가 불가능한 초기 A warmup, 참조 검증 전 B warmup, 확정 rank 제외·상품 제외·최초신호 이후 terminal은 분모에서 제외한다. stale/누락/미확인 입력은 DATA_UNAVAILABLE, 정상 변동률·실거래대금 조건 미달은 CONDITION_REJECT다. 실제 진입·신호·평가불가0건을 혼동하지 않는다.
- 공개 master 전달일은 취득일이며 거래소의 생성일을 꾸며 넣지 않는다. 당일 신규상장·분류변경의 최신성이 확인되지 않으면 해당 코드 미확인으로 남는다.
- 내부 호가 가상체결은 실제 체결 보증이 아니다. 실시간 서버 무통지 누락, Windows 디스크/네트워크/부하, 실제 Telegram 표시를 mock으로 확정하지 않았다.

## 2. P0 필수 수정

### 2.1 명시적 `copy` import

- 부모 import 블록에 `import copy`를 정확히 1회 추가한다.
- 테스트 harness가 선행 import하여 보완하지 못하도록 별도 프로세스에서 검사한다.
- ORB와 OPENING_LEADER의 모든 `copy.deepcopy()` 호출이 깨끗한 namespace에서 실행돼야 한다.

### 2.2 `open_paper_trade()` 선택 grid 복구

함수 초기에 다음 의미로 단일 변수를 만든다.

```python
selected_exit_strategies = (
    EXIT_STRATEGIES
    if exit_strategies is None
    else exit_strategies
)
```

- `or EXIT_STRATEGIES` 방식은 빈 dict를 암묵적으로 169 grid로 바꾸므로 사용하지 않는다.
- dict 타입, 비어 있지 않음, 각 rule의 `tp`·`sl` 존재와 숫자형을 검증한다.
- 전략 생성 loop와 진입 로그 모두 같은 `selected_exit_strategies`만 사용한다.
- 포지션 등록 전에 검증을 끝내어 실패 후 반쪽 포지션이 남지 않게 한다.
- 기존 호출 인자 없음: 169개
- ORB/OPENING_LEADER 등 `NEW_STOCK_EXIT_STRATEGIES` 전달: 20개
- ETF의 `ETF_EXIT_STRATEGIES` 전달: 16개
- 함수는 포지션 등록·추적기 시작·WS 구독·로그 후 trade_id를 예외 없이 반환해야 한다.

### 2.3 운영시간 단일 설정원

- Cell 1 사용자 설정의 `PROGRAM_START`, `PROGRAM_END`만 정의원으로 사용한다.
- 본체의 중복 `PROGRAM_START="08:00"`, `PROGRAM_END="20:00"` 재정의를 제거한다.
- NXT 세션 상수는 시장 세션 정의로 유지하되 프로그램 실행시간을 몰래 덮어쓰지 않는다.
- 시작 Telegram, 대기·종료 guard, QUICK REFERENCE가 실제 설정값과 일치하는지 검증한다.
- v2.1.1의 운영 기본값은 NXT 연구 연속성을 위해 Cell 1 한 곳에서 `08:00~20:00`으로 명시한다.
- 장외검증은 실제 시각이 08:00 이전 또는 20:00 이후여도 즉시 실행돼야 한다. 이를 위해 운영시간을 무제한 확장하지 않고 별도 replay 진입점을 사용한다.

### 2.4 반복 dict key 정리

`build_strategy_result_row()` 등 정적검사에서 확인된 중복 `rule_version` key 두 곳을 점검한다.
값이 동일한 단순 중복이면 하나만 남기되 CSV 컬럼과 최종 값은 변경하지 않는다. 값이 다르면
임의 선택하지 말고 원인을 보고한다.

### 2.5 v2.1.1 식별자와 출력 분리

- `STRATEGY_VERSION = "v2.1.1"`로 변경한다.
- 설정검증의 버전 assertion도 `v2.1.1`과 일치시킨다.
- 기존 v2.1 원본을 덮어쓰거나 이어 쓰지 않도록 release 출력 파일 suffix를 `_v211`로 변경한다.

## 3. 장외 검증 설계

단순히 프로그램을 08:00 이전이나 20:00 이후까지 실행하는 것만으로는 09:00 전용 분기에
도달하지 않는다. v2.1.1에는 네트워크 없는 가상시계 replay 진입점을 둔다.

권장 사용자 설정:

```python
OFF_HOURS_VALIDATION_MODE = False
```

원칙:

- 기본값은 `False`다.
- `True`일 때 `EXECUTION_MODE == "RESEARCH"`가 아니면 즉시 실패한다.
- token 발급, REST, WebSocket, Telegram, broker 주문함수를 호출하지 않는다.
- 실제 data 경로가 아닌 임시·전용 validation 경로만 사용한다.
- 검증 완료 또는 실패 후 worker·queue·임시파일을 정리하고 프로세스를 종료한다.
- `run_scanner()`의 실시간 무한 loop로 진입하지 않는다.
- 테스트 성공을 실제 시장 연결 성공이나 수익성 검증으로 표현하지 않는다.

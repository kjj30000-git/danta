## 1. 이번 버전의 확정 목표

기존 SNAPSHOT은 삭제하거나 대체하지 않는다. 기존 8개 시간축의 구조 연구를 유지하면서, 사용자가 원하는 차트 형태에 맞춘 별도 연구 전략 **`장기 보합 돌파`**를 추가한다.

목표 패턴:

> 장초반 큰 움직임 뒤, 가격대가 충분히 오래 좁게 유지되는 보합 구간을 찾고, 그 보합 상단을 벗어난 뒤 1분간 유지되는 돌파를 가상진입으로 기록한다.

이 전략은 FIRST_75_PASS의 장초반 추격 전략과 다르며, 기존 SNAPSHOT의 DIRECT/RECLAIM 연구와도 별개의 가상진입 stream이다.

## 2. SNAPSHOT과 장기 보합 돌파의 역할 분리

| 구분 | SNAPSHOT | 장기 보합 돌파 |
|---|---|---|
| 목적 | 기존 눌림 구조의 시간축별 관찰·비교 | 장기 보합 후 상단 돌파 진입 연구 |
| 판단 단위 | 30/60/90/120/150/180/210/240분 | 실제 완성된 보합 박스 1개 |
| 가상진입 | DIRECT·RECLAIM 각각 독립 기록 | 보합 박스별 최대 1회 |
| 알림 | 시간축별 누적 목록 | 보합완성·보합돌파 누적 목록 |

`PULLBACK_DISPLAY_STRATEGY="T200_S125"`는 SNAPSHOT/STRUCTURE 연구 표시·비교값이고, `LIVE_STRATEGY="T250_S150"`은 실제 FIRST_75 기준이다. 둘을 변경하거나 혼동하지 않는다.

## 3. 장기 보합 돌파 판정 설계

### 3.1 입력과 시간 안전성

- 유효하고 연속된 **완료 1분봉**만 사용한다.
- 현재 시각에 끝난 봉까지만 사용한다. 이후 봉·당일 종가·향후 고저가를 조건 또는 feature에 사용하지 않는다.
- 부분봉, 재접속 첫 봉, sequence gap, invalid bar는 보합 후보를 초기화하거나 해당 창을 무효 처리한다.
- 정규장 성과·알림에는 15:30 이후 NXT/장외 데이터를 섞지 않는다.
- `BALANCE_OBSERVE_END`(보합 관찰 종료)는 15:30으로 둔다.
- 신규 가상진입 종료 시각은 기존 `PULLBACK_NEW_ENTRY_END`(신규 진입 종료)인 15:10을 유지한다. 15:10 이후 보합완성은 기록할 수 있으나 신규 가상진입을 만들지 않는다.

### 3.2 매 분 계산·저장할 feature

기존 8개 SNAPSHOT horizon 모두에 대해 매 분 다음 값을 계산·저장한다.

- `balance_duration_min`(보합 지속시간)
- `balance_range_pct`(보합 가격폭)
- `balance_net_change_pct`(보합 순변화율)
- `trend_slope_pct_per_min`(분당 추세 기울기)
- `mean_abs_1m_return_pct`(평균 1분 절대변동률)
- `center_shift_pct`(중심가격 이동률)
- `direction_efficiency_ratio`(방향 효율성)
- `volume_contraction_ratio`(거래량 수축비율)
- `base_high`(보합 상단), `base_low`(보합 하단)
- `breakout_volume_ratio`(돌파 거래량비율)

v2.3.1에서 전부 NULL이었던 `range_compression_ratio`(가격폭 압축비율), `volume_contraction_ratio`(거래량 수축비율), `reclaim_volume_ratio`(재돌파 거래량비율)는 원인을 확인하고, 계산 불가 사유도 함께 저장한다. 과거 후보 구조값인 `base_range_pct`를 현재 보합 변동성 값으로 재사용하지 않는다.

### 3.3 첫 연구 기준값

아래 값은 첫 수집용 **가설**이며 실제 전략 기준으로 승격하지 않는다.

- `BALANCE_ALERT_MIN_DURATION`(보합 알림 최소시간): 60분
- `BALANCE_MAX_RANGE_PCT`(보합 최대 가격폭): 1.50%
- `BALANCE_MAX_ABS_NET_CHANGE_PCT`(보합 최대 절대 순변화율): 0.50%
- `BALANCE_MAX_ABS_SLOPE_PCT_PER_MIN`(보합 최대 절대 기울기): 0.010%/분
- `BALANCE_BREAKOUT_BUFFER_PCT`(상단 돌파 여유폭): 0.10%
- `BALANCE_INVALIDATE_BUFFER_PCT`(하단 이탈 무효 여유폭): 0.20%

30분은 원장·분석용으로 계속 수집하지만, 장기 보합 돌파의 `보합완성` 알림은 60분 이상부터 낸다. 90분·120분 등 더 긴 보합은 같은 박스가 지속된 상태로만 기록하며, horizon별 중복 가상진입을 금지한다.

### 3.4 상태 전환

1. `BALANCE_CANDIDATE`(보합 후보): feature는 저장하지만 텔레그램 알림·가상진입 없음.
2. `BASE_READY`(보합 기준 충족): 60분 이상 조건을 처음 만족한 시점. 보합 박스 상·하단을 고정하고 `보합완성` 이벤트를 1회 기록.
3. `BASE_MATURE`(보합 지속): 더 긴 시간축을 충족해도 같은 박스를 유지한다. CSV에는 기록하되 30분 누적 메시지에는 별도 줄을 추가하지 않는다.
4. `BREAKOUT_WATCH`(돌파 관찰): 완료 1분봉 종가가 보합 상단 +0.10%를 넘음. CSV만 기록.
5. `BASE_BREAKOUT`(보합 돌파 가상진입): 다음 완료 1분봉도 보합 상단 이상을 유지할 때, 다음 수신 tick 기준 가상체결을 1회 생성.
6. `BASE_EXPIRED`(보합 무효화): 하단 -0.20% 이탈, 연속성 훼손, 더 긴 새 보합 박스로 대체, 또는 세션 종료. CSV만 기록.

재돌파는 첫 버전에서 별도 가상진입을 만들지 않는다. 같은 보합 박스에서 `BASE_BREAKOUT`은 최대 한 번이다.

### 3.5 출력

신규 원장 파일:

- `pullback_balance_evaluations_v232.csv`
- `pullback_balance_events_v232.csv`
- `paper_trades_v232.csv`에는 `entry_mode="PULLBACK_BALANCE_BREAKOUT"`(장기 보합 돌파 가상진입) 행을 추가

기존 `pullback_snapshot_evaluations_v231.csv`, `pullback_structure_signals_v231.csv`, `paper_trades_v231.csv`의 의미와 과거 파일은 변경하지 않는다. 신규 전략은 기존 63-grid(TP +1.00~+3.00%, SL −0.75~−2.25%)를 사용하되, 성과는 독립 `trade_id`(거래 식별자) 기준으로 분석한다.

## 4. 30분 누적 Telegram 알림: 확정 형식

### 4.1 발송 주기와 공통 규칙

- 발송 시각: 09:30, 10:00, 10:30, 11:00, 11:30, 12:00, 12:30, 13:00, 13:30, 14:00, 14:30, 15:00, 15:30.
- 각 메시지는 해당 시각까지의 **당일 누적**이다.
- 전략별 최초 신호만 남긴다. 동일 종목·동일 전략의 중복 줄은 금지한다.
- 기존처럼 **하나의 Telegram 채팅방**으로 보낸다. 채팅방을 전략별로 분리하지 않는다.
- 기존 한 개의 긴 누적 메시지를 전략별로 나눈 여러 개의 간단한 말풍선으로 발송한다.
- 메시지에 종목명·6자리 종목코드·신호시각만 표시한다. 가격·점수·상태 설명을 추가하지 않는다.
- 재시작·재전송·outbox(발송 대기함)에서도 동일 시각·동일 전략 메시지가 중복 전송되지 않아야 한다.

### 4.2 말풍선 제목과 내용

기존 전략:

```text
[BASE]
1. 루닛(328130) - 09:06:04

[FIRST 75 PASS]
1. 루닛(328130) - 09:06:04

[PULLBACK STRUCTURE ENTRY]
1. 코리아써키트(007810) - 09:18:21
```

SNAPSHOT은 시간축별 별도 말풍선으로 보낸다. 각 목록은 해당 시간축의 `READY`(기준 충족) 최초 시점만 표시한다.

```text
[SNAPSHOT 60분]
1. 루닛(328130) - 10:22:00
2. 대우건설(047040) - 10:34:00
```

새 전략 제목은 반드시 한글로 표기한다.

```text
[장기 보합 돌파]
1. OCI홀딩스(010060) - 90분 보합완성 - 11:57:00
2. OCI홀딩스(010060) - 보합돌파 - 12:27:00
```

`보합완성`과 `보합돌파`는 같은 종목에서도 각각 1회씩만 보인다. 후보·지속·관찰·무효 상태는 CSV에만 남기고 Telegram 누적 목록에는 표시하지 않는다.

### 4.3 구현 주의사항

- 기존 `v220_summary_text`(누적 요약 메시지 생성)는 한 개 문자열을 만드는 방식이다. 전략별·시간축별 문자열 목록을 반환하도록 국소 변경한다.
- outbox(발송 대기함) key는 `SUMMARY:{date}:{hhmm}:{strategy_or_horizon}`(날짜·시각·전략 또는 시간축)로 분리한다.
- 보합 전략 누적키는 종목·이벤트 종류 기준으로 분리한다. 동일 종목의 `보합완성`과 `보합돌파`는 각각 표시하되, 같은 이벤트는 중복 표시하지 않는다.
- 전송 순서는 BASE → FIRST 75 PASS → PULLBACK STRUCTURE ENTRY → SNAPSHOT 30~240분 오름차순 → 장기 보합 돌파로 고정한다.
- 해당 전략·시간축에 신호가 없으면 현재 누적 요약의 `없음`과 동일하게 한 줄로 보낸다.

## 7. 금지사항

- 장기 보합 돌파를 실제 또는 키움 모의 주문에 연결하지 않는다.
- 15:30 이후 데이터를 정규장 진입·성과 판정에 사용하지 않는다.
- 사후 수익·실패를 보고 보합완성/돌파 조건을 수정하지 않는다.
- SNAPSHOT의 시간축을 삭제하거나 90분 이상으로 강제하지 않는다.
- SNAPSHOT과 장기 보합 돌파의 표본·가상진입을 합산해 성과를 판단하지 않는다.
- 기존 전략을 새 알림 형식으로 묶어 한 개의 긴 메시지로 되돌리지 않는다.

이 문서는 2026-09-28 장기 보합 돌파 설계와 30분 누적 Telegram 알림 형식의 최신 확정 기록이다.

## 3. 코스피·코스닥 시점별 수집

- 후보 등록·신호·가상 체결에 코스피와 코스닥 양쪽의 정규장 시가, 현재값, 시가 대비 수익률과 최근 5분 변화율, 시세·수신 시각, 출처, 경과시간 및 상태를 연결한다. 판단 시점까지 수신된 동일 세션 값만 사용하고 판단 이후 응답의 소급 연결을 금지한다.
- 시장 대비 상대강도는 종목 정규장 시가 대비 수익률에서 해당 종목 소속 시장 지수의 같은 기준 수익률을 뺀 %p다. 시장·시가 미확인 또는 5분 이력 부족은 해당 값만 결측 처리한다. `MISSING`(값 없음), `STALE`(유효시간 초과)을 구분하고 신호 경로에서 지수 응답을 동기 대기하지 않는다. 신선도 한도는 API 계약 확인 후 설정값으로 명시하고 경계를 시험한다.
- 키움 공식 문서에서 `0J`(실시간 업종지수)와 `ka20001`(업종현재가) 실제 입력·출력, 시장 코드·시각 필드를 확인한다. 실시간 우선, REST는 시가 초기화·제한된 대체 조회 후보. API 요청 제한과 기존 우선순위를 지킨다. 장중 실수신이 검증되지 않았으면 검증 범위를 기록한다.
- 지수·상대강도는 관측 변수다. 지수 상승/하락과 상대강도 양수/음수의 교차표를 사후 분석한다. 업종 대비 강도는 매핑이 확인될 때, 전날 밤 나스닥은 날짜별 보조 변수로 후속 적용한다. 기존 스캐너 단면 proxy를 실제 지수 값으로 대체 사용하지 않는다.

## 4. 기존 연구와 운영

- BASE/FIRST의 장중 가상 신호와 수집 범위를 보존한다. 새 실험만 09:05~09:30으로 제한한다. 기존 가상 청산은 부모 정책에 따르며 기본 대표 조합 중심 축소를 적용하고 기존 169-grid(청산 조합)는 설정으로 복원할 수 있게 한다.
- 장기보합은 오후 별도 연구로 집계한다. 부모의 관찰·진입 규칙과 진폭·형태 기준을 보존하며 대표 +2.0%/-1.25%와 15:20 가상 청산을 사용한다. 성숙했으나 당시 미돌파인 박스도 시각과 특징을 저장한다. 후속 비교는 같은 시점·지속시간·진폭·시장 환경을 맞춰 돌파의 추가 효과를 평가한다. 박스 관찰 종료 15:30과 가상 포지션 청산 15:20을 분리한다.
- SNAPSHOT·STRUCTURE·ETF의 상시 가상진입 및 그리드 계산은 기본 OFF. 옵션 복원과 과거 스키마 해석을 보존한다.
- Telegram은 동일 방의 전략별 별도 말풍선과 기존 09:30~15:30 30분 누적 요약을 유지한다. 신규 전략명은 한글로 표시한다. 후보 등록은 CSV에만 남긴다. 장애 알림에 종목명·코드·영향 범위·원인·복구 상태를 적는다. `DELIVERY_UNKNOWN`(발송 확인 불가)은 자동 재전송하지 않는다.

## 5. 오류 수정

1. **한 후보의 오류를 격리.** `v231_check_health`가 시세 공백·유효봉 없음·고점 미생성과 원장 불일치를 한 이유로 묶어 전역 중단하는 분기를 분리한다. 10/2 에코프로 이후 10/28·11/2에도 재발했다. 시세 문제는 해당 후보를 `DATA_UNAVAILABLE`(데이터 사용 불가)로 두고 다른 후보의 신규 진입 및 기존 포지션 추적을 이어간다. 연속 유효봉 2개를 복구 기본값으로 삼고 공백을 건너지 않는 새 관찰 구간에서 판정을 재개한다. 복구 중 관찰한 연속 정상봉만 새 구간에 사용한다.
2. **공용 저장 실패는 별도 처리.** 실패한 공용 필수 원장을 제한적으로 재시도한다. 계속 실패하거나 중복·누락을 안전하게 판별할 수 없는 공용 상태 불일치가 있을 때 해당 원장에 의존하는 전체 신규 진입을 멈춘다. 가능한 시세 수신·기존 포지션 추적·오류 기록을 이어간다. 재개는 원장 정합성 확인 이후에만 허용한다.
3. **과부하와 재접속.** 틱 합치기·큐 포화·재접속·시퀀스 공백의 원인과 영향을 별도 집계한다. 분봉 생성, 전략 계산, 저장 적체를 구분하고 유실된 구간을 정상 처리하지 않는다. 큐 증설만으로 해결했다고 판단하지 않는다.
4. **15:20 청산.** `_v20_grid_family`(그리드 분류)가 PULLBACK을 기존군으로 반환해 `v20_force_close_research_due`(연구 강제청산)에서 빠지는 문제를 수정한다. 청산 정책을 전략별로 명시하고 등록 누락을 시작 검증에서 발견한다. 15:20까지 확보한 유효 가격과 경과시간을 사용하며 이후 틱이나 장후 가격을 섞지 않는다. 재시작·실패 재시도에도 마감 이전 가격만 쓰고 사용할 가격이 없으면 미확정 처리한다.
5. **종료와 복구.** 신호·가상 체결·청산·미확정과 원장 저장을 대조한다. 정상 종료는 큐 배출과 저장 확인을 남긴다. 강제 종료 후 원장과 체크포인트를 대조하고 기록 직후 재시작에도 중복되지 않게 한다. 10/14·10/16 같은 중도 누락은 단순 조건 미충족과 구분한다.

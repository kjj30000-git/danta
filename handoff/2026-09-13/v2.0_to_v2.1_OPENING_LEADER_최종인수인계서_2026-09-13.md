## 1. 사용자 의도와 이번 버전의 핵심

사용자는 FIRST_75_PASS의 점수를 낮추거나 74점에서 조기진입하려는 것이 아니다. 최초 컨셉인 **전일 대비 등락률 상위 주도주**로 돌아가, 장 초반 실제 가격 움직임을 이용하는 완전히 새로운 전략을 찾고자 한다.

정확한 연구 질문은 다음과 같다.

> 09:00~09:15의 전일 대비 등락률 상위 종목 중 거래 가능한 유동성을 가진 종목에서, 초기 고점 직접 돌파·돌파 후 눌림 재확인·시장대비 상대강도 중 어느 진입구조가 비용 반영 후 반복 가능한 우위를 보이는가?

따라서 v2.1은 다음 원칙을 지킨다.

- 등락률 상위가 **발견 기준**, 거래대금은 **체결 가능성과 잡음 제거 기준**이다.
- FIRST_75 점수는 신규 전략의 진입조건에 사용하지 않는다.
- FIRST_75/CALM/기존 거래대금 ORB는 대조군으로 보존한다.
- 새 전략은 모두 내부 가상매매이며 실제·키움 모의주문에 연결하지 않는다.
- 성공 사례만 사후 분석하지 않고, 진입하지 않은 관찰 후보와 SKIP 사유도 함께 남긴다.

## 2. v2.0에서 확인된 현재 구조와 변경 이유

부모 v2.0의 기존 ORB 계열은 다음 구조다.

- 09:00 직후 **실제 거래대금 상위 20종목**을 고정한다.
- 09:00:00~09:04:59 opening range를 만든다.
- `ORB_DIRECT`, `ORB_RETEST`, `ORB_RS_RETEST`를 09:05~10:30에 가상진입한다.

이는 유효한 독립 대조군이므로 변경하거나 이름을 바꾸지 않는다. v2.1의 `OPENING_LEADER`는 **등락률 상위 universe**, **09:00~09:15 조기판정**, **동적 순위 이력**을 사용하는 별도 연구군이다.

기존 `NEW_EARLY_ACCEL_SHADOW`, `NEW_FIRST_PULLBACK_SHADOW`, `NEW_WATCH_RECLAIM_SHADOW`는 과거 성과 열위로 OFF이며 재활성화하지 않는다. 새 전략은 이 함수·상태·CSV 이름을 재사용하지 않는다.

## 6. 후보 universe 설계

### 6.1 데이터 소스와 API 부하

- 기존 주식 스캐너의 `KA10027` 코스피·코스닥 등락률 상위 결과를 재사용한다.
- `OPENING_LEADER`만을 위한 추가 REST 반복호출을 만들지 않는다.
- 기존 실제 거래대금 조회 결과, WebSocket/현재가 quote, 시장 proxy를 재사용한다.
- 같은 scan sample의 timestamp를 보존하고 서로 다른 시점 값을 한 행에 현재값처럼 섞지 않는다.

### 6.2 후보 등록

- 시장별 등락률 상위 10개를 기본 관찰 대상으로 한다.
- 코스피·코스닥 통합 최대 20개다.
- `is_excluded_stock` 등 부모의 ETF·우선주·스팩·관리/제외종목 필터를 재사용한다.
- 관찰 시점에는 상승률 +2% 이상이면 등록할 수 있다.
- 진입 시점에는 +5~+20%, 실제 거래대금 20억원 이상이어야 한다.
- 거래대금 순위로 universe를 만들지 않지만 거래대금 원시값·출처·시각·유효성을 반드시 기록한다.
- 프로그램이 09:00 이후 시작했으면 누락 구간을 만들어내지 말고 `LATE_START`와 실제 최초 관찰시각을 기록한다.

### 6.3 동적 후보와 생존자편향 방지

- 09:00에 고정된 종목만 보는 방식이 아니라 09:15까지 새로 등락률 상위권에 들어온 종목도 등록한다.
- 한 번 등록된 종목은 성공 여부와 무관하게 그날 관찰 episode를 보존한다.
- 나중에 상승한 종목만 과거 시점으로 소급 등록하지 않는다.
- 후보 이탈, 재진입, 최초·현재·최고·최저 순위를 모두 기록한다.

## 8. 시간에 따른 기준고점 정의

09:05 이전에도 진입할 수 있으므로 5분 고점을 미래정보로 사용하면 안 된다.

- 09:01~09:02: 최소 60초의 유효 관찰이 완성된 종목만 현재까지의 최고가 사용
- 09:02~09:05: 최초 관찰부터 현재 판정 직전까지의 최고가 사용
- 09:05~09:15: 09:00~09:04:59에 실제 관찰된 opening high 사용 가능
- 현재 tick을 기준고점 계산에 먼저 포함한 뒤 같은 tick에서 돌파로 판정하는 자기참조를 금지한다.
- `reference_high_source`, `reference_high_cutoff_time`, `observation_span_sec`, `max_observation_gap_sec`, `range_complete`를 저장한다.
- 최초 관찰 60초 미만, 시각 역전, 가격 이력 공백 등은 `DATA_UNAVAILABLE`로 SKIP한다.

## 9. 공통 진입 자격조건

세 전략의 공통 자격조건은 다음과 같다.

```text
09:01:00 <= decision_time <= 09:15:00
현재 등락률 +5.0% ~ +20.0%
해당 시장 등락률 순위 상위 10위
실제 거래대금 >= 20억원
최소 유효 관찰 60초
제외종목 아님
데이터 timestamp·age 유효
동일 종목·동일 전략 당일 미진입
```

공통 조건은 각 원시값과 개별 pass/fail Boolean을 모두 `paper_entry_decisions`에 기록한다. 하나라도 불명확하면 유리하게 추정하지 않고 SKIP한다.

## 10. 전략별 진입 규칙

### 10.1 `OPENING_LEADER_DIRECT`

- 판정 직전까지 확정된 기준고점 대비 +0.10% 이상 돌파한다.
- 직전 60초 상승률은 +2.00% 이하여야 한다.
- 돌파 기준을 넘은 최초 유효 tick에서 가상진입한다.
- 돌파를 확인한 뒤 이미 가격이 기준고점에서 과도하게 멀어진 경우의 실제 초과폭을 저장한다.
- `DIRECT`에는 retest·시장상대강도 조건을 섞지 않는다. 가짜 돌파를 포함한 대조군 역할이다.

### 10.2 `OPENING_LEADER_RETEST`

순서가 반드시 지켜져야 한다.

1. 기준고점 +0.10% 이상에서 `breakout_seen_at` 확정
2. 이후 별도 tick에서 기준고점 부근으로 되돌림
3. 되돌림 가격이 기준고점 대비 -0.50% 이상을 유지하고 관찰 opening low를 이탈하지 않음
4. 이후 별도 tick에서 기준고점 +0.05% 이상 재회복
5. 09:15 이전이면 재회복 가격으로 가상진입

- 같은 tick에서 breakout→retest→reclaim을 모두 완성할 수 없다.
- 돌파 전의 과거 눌림을 사후에 retest로 해석하지 않는다.
- `breakout_seen_at < retest_seen_at < reclaim_seen_at` 시간 invariant를 검사한다.
- pullback 깊이, 소요시간, 저점, 재회복 속도를 기록한다.

### 10.3 `OPENING_LEADER_RS`

- `OPENING_LEADER_RETEST`의 상태전환을 모두 만족한다.
- 종목 전일대비 상승률 − 해당 시장 proxy 전일대비 상승률이 +0.20%p 이상이다.
- 코스피 종목은 코스피 proxy, 코스닥 종목은 코스닥 proxy를 사용한다.
- proxy timestamp가 45초보다 오래됐거나 시장 매핑이 없으면 `MARKET_DATA_UNAVAILABLE`로 SKIP한다.
- 비교 창은 `PREV_CLOSE_TO_NOW`로 명시하고 종목·시장 수익률의 기준시점을 일치시킨다.

- 기존 거래대금 ORB의 `orb_states`와 신규 state 공유

- 관찰하지 않은 SKIP 종목을 결과에서 누락해 성과를 과대평가
